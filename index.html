OpenCode 是一个功能强大的开源 AI 编程代理：支持多种模型，原生 LSP，专注终端工作流；你可以把它当作一个可被远程控制的客户端/服务器系统，而不是一个花哨的 UI。

快速安装 GitHub Docs

为什么它不“像个模板”

  • 模型无关 Claude / OpenAI / Google / 本地模型 — 自由切换。
  • 原生 LSP 不是“做做样子”的补全：把语言服务当作底座。
  • 终端优先 由严肃 terminal 用户打造：快速、可脚本化、可组合。
  • 客户端/服务器 可在电脑运行服务，移动端/桌面端只是“遥控器”。
  • 内置代理 build：执行；plan：推演。两种心智模式一键切换。

特性不是“堆叠”，而是决策。

删掉那些只会占空间的装饰，留下对开发体验有硬收益的东西：可控性、透明度、可扩展性。

  • 01 100% 开源

    完全开源透明：你可以审计、修改、分发，不被专有实现锁死。

  • 02 模型无关

    不绑定任何供应商；支持 Claude、OpenAI、Google，或本地运行的模型。

  • 03 原生 LSP 支持

    语言服务不是“插件”，而是默认能力：补全、跳转、诊断都更可靠。

  • 04 专注终端体验

    为终端而生：速度快、依赖少、可脚本化，适合大多数真实工作流。

  • 05 客户端/服务器架构

    允许在电脑上运行 OpenCode，通过移动应用远程控制，前端只是客户端之一。

  • 06 智能代理

    内置多个专业代理：build 处理开发任务，plan 用于分析与规划。

安装：用最短的路径，到达可用。

命令即界面。每个安装方式都保持可复制、可自动化、可回滚。

YOLO 安装 推荐

一键安装脚本，最快路径。

curl -fsSL https://opencode.ai/install | bash

npm / bun / pnpm / yarn

通过包管理器全局安装。

npm i -g opencode-ai@latest

Homebrew

macOS 和 Linux 用户。

brew install opencode

Scoop

Windows 用户。

scoop bucket add extras
scoop install extras/opencode

Chocolatey

Windows 用户。

choco install opencode

Arch Linux (AUR)

使用 AUR。

paru -S opencode-bin

mise

跨平台版本管理。

mise use -g github:sst/opencode

Nix

Nix 用户。

nix run nixpkgs#opencode

Custom install dir

安装脚本支持自定义安装路径（优先级如下）：
OPENCODE_INSTALL_DIR → XDG_BIN_DIR

# 方式 1: OPENCODE_INSTALL_DIR
OPENCODE_INSTALL_DIR=/usr/local/bin curl -fsSL https://opencode.ai/install | bash

# 方式 2: XDG_BIN_DIR
XDG_BIN_DIR=$HOME/.local/bin curl -fsSL https://opencode.ai/install | bash

两种代理：两种姿势。

你不需要“更多按钮”，你只需要明确的模式切换。用 Tab 在 build / plan 之间切换。

build

default

默认代理，拥有完整开发权限，适合日常“把事情做完”。

  • 完整的文件读写权限
  • 可执行任意终端命令
  • 适合开发、重构、修复
  • 智能代码生成与迭代

plan

read-only

只读代理，适合代码分析与规划：把风险前置，把改动后置。

  • 默认拒绝文件编辑
  • 运行命令前会询问确认
  • 适合探索不熟悉的代码库
  • 更安全的推演与评审

general sub-agent

用于复杂搜索和多步骤任务（内部使用）。可在消息中使用 @general 调用。

FAQ

少一些“营销式解释”，多一些直接答案。

OpenCode 和那个重名的仓库有什么关系？

没有任何关系。那个仓库是另一个项目，只是名称巧合相同。若想了解故事背景：阅读原贴。

安装前需要做什么准备吗？

如果你之前安装了 0.1.x 之前的版本，建议先卸载旧版本再安装新版本；新用户直接使用安装命令即可。

如何配置 OpenCode？

OpenCode 支持环境变量与配置文件等方式。详见 官方文档。

支持本地模型吗？

支持。OpenCode 设计为模型无关：既能使用各云服务商 API，也能配置本地运行的模型（如 Ollama、LM Studio 等）。
