开源 AI 编程助手

OpenCode 是一个功能强大的开源 AI 编程代理，支持多种 AI 模型，提供原生的 LSP 支持和卓越的终端开发体验。

快速安装 GitHub

为什么选择 OpenCode？

🔓 100% 开源

完全开源透明，你可以查看、修改和分发代码，不受任何专有限制。

🔧 模型无关

不与任何提供商绑定，支持 Claude、OpenAI、Google 或本地模型，自由选择。

📝 原生 LSP 支持

开箱即用的语言服务器协议支持，提供智能代码补全和导航。

🖥️ 专注终端体验

由 Neovim 用户和 terminal.shop 创建者打造，极致的终端开发体验。

🏗️ 客户端/服务器架构

允许在电脑上运行 OpenCode，通过移动应用远程控制，前端只是客户端之一。

🤖 智能代理

内置多个专业代理，build 代理处理开发任务，plan 代理用于代码分析和规划。

安装指南

支持多种安装方式，选择最适合你的方法

🚀 YOLO 安装 推荐

一键安装脚本，最快捷的方式

curl -fsSL https://opencode.ai/install | bash

📦 npm / bun / pnpm / yarn

通过包管理器全局安装

npm i -g opencode-ai@latest

🍺 Homebrew

macOS 和 Linux 用户

brew install opencode

🎃 Scoop

Windows 用户

scoop bucket add extras
scoop install extras/opencode

🍫 Chocolatey

Windows 用户

choco install opencode

🦊 Arch Linux

使用 AUR

paru -S opencode-bin

🔧 mise

跨平台版本管理

mise use -g github:sst/opencode

❄️ Nix

Nix 用户

nix run nixpkgs#opencode

⚙️ 自定义安装路径

安装脚本支持自定义安装路径，按以下优先级选择：

# 方式 1: OPENCODE_INSTALL_DIR
OPENCODE_INSTALL_DIR=/usr/local/bin curl -fsSL https://opencode.ai/install | bash

# 方式 2: XDG_BIN_DIR
XDG_BIN_DIR=$HOME/.local/bin curl -fsSL https://opencode.ai/install | bash

智能代理

OpenCode 内置两个核心代理，使用 Tab 键切换

🔨 build 代理

默认代理，拥有完整开发权限

  • 完整的文件读写权限
  • 可执行任意终端命令
  • 适合日常开发工作
  • 智能代码生成和重构

📋 plan 代理

只读代理，适合代码分析和规划

  • 默认拒绝文件编辑
  • 运行命令前会询问确认
  • 适合探索不熟悉的代码库
  • 安全的代码分析工具

🔍 general 子代理

用于复杂搜索和多步骤任务，内部使用，可在消息中使用 @general 调用

常见问题

OpenCode 和那个重名的仓库有什么关系？

没有任何关系！那个仓库是另一个项目，只是名称巧合相同。如果你好奇这个故事的来龙去脉，可以在这里阅读。

安装前需要做什么准备吗？

如果你之前安装了 0.1.x 之前的版本，建议先卸载旧版本再安装新版本。对于新用户，直接使用上述安装命令即可。

如何配置 OpenCode？

OpenCode 支持多种配置方式，包括环境变量和配置文件。详细的配置说明请查看官方文档。

支持本地模型吗？

是的！OpenCode 设计为模型无关，不仅支持各大云服务商的 API，还可以通过配置使用本地运行的模型，如 Ollama、LM Studio 等。
